# Автотесты для UI Stellar Burgers

## Задание 3. Автотесты для UI

Автоматизированные UI-тесты для веб-приложения ([Stellar Burgers](https://stellarburgers.education-services.ru/)). Тесты покрывают основную функциональность конструктора бургеров и раздела «Лента заказов».

### Переходы по страницам:
- переход по клику на «Конструктор»;
- переход по клику на раздел «Лента заказов».

### Работа с ингредиентами:
- открытие модального окна с деталями ингредиента;
- закрытие модального окна кликом по крестику;
- увеличение счетчика ингредиента при добавлении в заказ.

### Счетчики заказов:
- увеличение счетчика «Выполнено за всё время» при создании заказа;
- увеличение счетчика «Выполнено за сегодня» при создании заказа;
- появление номера заказа в разделе «В работе» после оформления.

```
├── conftest.py              # Фикстуры для тестов

├── pages/
│   ├── base_page.py         # Базовые методы для работы со страницами
│   ├── login_page.py        # Методы для страницы авторизации

└── .gitignore

```

## Технологии

- **Python 3.11+**
- **pytest** - фреймворк для тестирования
- **allure-pytest** - для генерации отчетов
